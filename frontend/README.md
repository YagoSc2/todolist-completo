# Todolist – Frontend (React + Vite)

```bash
npm install
cp .env.example .env   # ajuste VITE_API_URL se o backend não estiver em localhost:3333
npm run dev            # http://localhost:5173
```

O backend (Fastify + MySQL) precisa estar rodando; o CORS dele já libera `http://localhost:5173` por padrão.
